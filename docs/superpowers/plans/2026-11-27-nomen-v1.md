# Nomen v1 Implementation Plan

> **For agentic workers:** Steps use checkbox (`- [ ]`) syntax for tracking. Execution method: Native (the user asked for the whole app to be built in this session without stopping).

**Goal:** Build Nomen v1, the on-device file-naming menu bar app in `docs/SPEC.md`, as a Swift package plus an Xcode app, with every code-controlled acceptance criterion pinned by an automated test.

**Architecture:** The model returns fields and deterministic code builds the name. Pure logic (formatting, guards, dates, eligibility, rules, learning) lives in `NomenCore` and is tested on Linux and macOS. File safety (`NomenFS`), storage (`NomenStore`), model orchestration (`NomenModel`) and the pipeline (`NomenEngine`) sit behind small protocols, so the full pipeline runs in tests with fake extractors and a fake model. Apple-only frameworks (FoundationModels, Vision, PDFKit, Quick Look, AppKit, SwiftUI, FinderSync, App Intents) are confined to adapters behind `#if canImport(...)` and to the app targets.

**Tech Stack:** Swift 6.4 (Swift 6 language mode, complete concurrency checking), Swift Testing, GRDB 7, SwiftUI + AppKit, FoundationModels, Vision, PDFKit, QuickLookThumbnailing, NaturalLanguage, FinderSync, AppIntents, XcodeGen for the project file.

**Spec:** `docs/SPEC.md`

## Global Constraints

- macOS 27.0 deployment target, arm64 only (A2).
- Swift 6 language mode; zero warnings (`-warnings-as-errors` in CI) (A1).
- GRDB is the only third-party dependency (3.2, A5).
- App entitlements exactly: app-sandbox, files.user-selected.read-write, files.downloads.read-write, files.bookmarks.app-scope, application-groups. Finder extension: app-sandbox, application-groups (3.2, A3).
- No network, Apple Events or temporary-exception entitlements (3.2).
- Marker xattr name: `com.yourcompany.Nomen.original` (3.3).
- All numeric defaults come from one file, `Sources/NomenCore/Policy/Defaults.swift`, mirroring 3.4.
- Extracted text never touches disk; stored fields ≤ 200 characters (3.18, E4, W1).
- No `TODO`/`FIXME` in shipped sources (A8).

## Review Focus

1. **A name that already has the target spelling (case-only change on a case-insensitive volume).** Expect: renaming `invoice.pdf` → `Invoice.pdf` works and is not treated as a collision with itself. Test in NomenFS executor tests.
2. **Files Nomen restored by undo arriving back into a watched folder.** Expect: never re-processed (marker state restored). Test in engine undo tests.
3. **Subjects consisting only of PII or never-include words.** Expect: valid name, Low confidence, no crash, no leaked digits. Test in formatter property tests.
4. **A watched folder disappearing while files are queued.** Expect: queued items stay, folder shows Needs attention, nothing is executed against a missing path. Test in engine tests.
5. **Clock or time-zone change between detection and execution.** Expect: dates come from file metadata/candidates rendered in the local calendar at format time, deterministic for a fixed time zone. Test in formatter date tests with explicit time zones.
