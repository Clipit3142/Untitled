# Untitled

Untitled gives new screenshots and downloads clear names in your style, on-device, with undo for everything.

It is a macOS 27 menu bar app. It watches the folders you choose, reads each new file on this Mac (Vision, PDFKit,
Quick Look, and Apple Intelligence through Foundation Models), and renames it with a deterministic formatter in the
style you pick. Nothing leaves the Mac: the app has no network entitlement.

The full product specification, including every acceptance criterion, is in [`docs/SPEC.md`](docs/SPEC.md). What has
been verified so far, and what still needs a Mac, people or Apple, is in [`docs/ACCEPTANCE.md`](docs/ACCEPTANCE.md).

## Layout

| Path | What it is |
|---|---|
| `UntitledKit/` | The Swift package with all the logic and the UI modules (Swift 6, strict concurrency) |
| `UntitledKit/Sources/UntitledCore` | Formatter, sanitizer, guards, date parsing, generic-name detector, eligibility, rules, learning |
| `UntitledKit/Sources/UntitledFS` | Watcher, snapshots, stability gate, journal, executor, marker, bookmarks |
| `UntitledKit/Sources/UntitledStore` | `config.sqlite` and `history.sqlite` (GRDB, the only dependency) |
| `UntitledKit/Sources/UntitledModel` | Schema builder, budgeter, error policy, Basic naming, the Foundation Models adapter |
| `UntitledKit/Sources/UntitledExtract` | Vision, PDFKit, Quick Look and metadata readers, app timeline |
| `UntitledKit/Sources/UntitledEngine` | The pipeline: queue, decide, execute, undo, learning, notification planning |
| `UntitledKit/Sources/UntitledUI` | Presentation logic and the app model (tested everywhere), SwiftUI views and the AppKit shell (macOS) |
| `UntitledKit/Sources/UntitledShared` | The app ↔ Finder extension handoff through the app-group container |
| `App/` | The app target: entry point, Shortcuts actions, Info.plist, entitlements, privacy manifest, assets |
| `FinderExtension/` | The Finder Sync extension |
| `Untitled.xcodeproj` | Generated by `scripts/generate_xcodeproj.py`; checked by `scripts/check_xcodeproj.py` |
| `scripts/` | Acceptance gates: entitlements (A3), release hygiene (A8), coverage (A6), project checks |

## Building

On a Mac with Xcode 27 and macOS 27:

```bash
xcodebuild -project Untitled.xcodeproj -scheme Untitled -configuration Release -destination 'platform=macOS,arch=arm64' build
```

To run it signed (needed for the app group, the Finder extension and notifications), open `Untitled.xcodeproj`,
set your team on both targets, and replace `com.yourcompany` in the bundle identifiers, the app group and the marker
attribute name with your own reverse domain.

## Testing

```bash
swift test --package-path UntitledKit
```

The package tests run on macOS and on Linux. On Linux the Apple-only readers, the Foundation Models adapter, FSEvents
and the SwiftUI/AppKit code are compiled out; everything else runs, including the engine end to end with fake models
and readers.

Slow tests (a 2 GB file written over 60 s) run with `UNTITLED_SLOW_TESTS=1`.

The acceptance gates:

```bash
python3 scripts/check_entitlements.py
```

```bash
scripts/check_release_hygiene.sh
```

```bash
python3 scripts/coverage.py
```
